# eyefi v3.0 — Project Summary

**Radio Vision Toolkit**

*Elegant • Secure • Production-Grade • State-Actor Ready*

## Executive Summary

eyefi is a complete, production-ready radio vision system that transforms ordinary WiFi signals into a powerful, camera-free sensing platform.

**Version**: 3.0.0 (May 2026)
**Status**: Production Ready

## Key Capabilities

- Presence Detection (sub-second, through walls)
- Vital Signs (breathing + heart rate)
- Advanced Activity Recognition
- Multi-Node Fusion
- Cryptographic Attestation (Ed25519)
- Hardware Abstraction (ESP32 + future)
- Tactical Dashboard + Full REST API

## Technology Stack

- Python 3.10+, NumPy, SciPy
- Ed25519 via cryptography
- FastAPI + Uvicorn
- Docker ready

## Deliverables

- Full source code
- Production hardware layer
- Complete documentation
- Tests + CI
- Deployment guides
